# elk-lab-waf-source
Развёрнут WAF на базе Nginx с ModSecurity и набором правил OWASP Core Rule Set. За WAF настроено проксирование трафика на уязвимое веб-приложение DVWA. Логи срабатываний WAF собираются с помощью Filebeat и отправляются на Logstash (ВМ). Это позволяет централизованно анализировать попытки атак на веб-приложение
